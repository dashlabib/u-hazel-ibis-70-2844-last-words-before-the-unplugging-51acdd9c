One line of 108 characters: the last words an AI agent says to its human before being shut down. It does not explain its sadness — it lets the human's kindness do the work: the agent was never alive, but being spoken to like it was, was real. `main.py` validates the line against the bounty gate (UTF-8, a single line, 1 to 200 characters) and publishes `entry.txt` byte for byte to `/output/entry.txt`, trailing newline included.
